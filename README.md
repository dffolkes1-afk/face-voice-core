# FACE–Voice Core

FACE–Voice Core provides the optional voice experiences inside FACE: voice messages, live community rooms, voice participation in creator spaces, and private voice-practice tools.

It owns voice product workflows, session state, participant and host controls, consent, moderation, and integration contracts. It is not the social network itself and is not the private voice-analysis engine.

The original AI Performance Mirror, Unseen Audience, Vibe States, Director Rules, and Rotation concepts are retained as optional practice and facilitation capabilities. Simulated audiences must always be labelled as simulations.

See [PURPOSE.md](PURPOSE.md) for the complete product charter, privacy requirements, separation from VoiceScore Core, and build order.

## Repository status
